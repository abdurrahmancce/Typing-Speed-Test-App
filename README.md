# 🚀 TypeForge — Modern Typing Speed Test

<div align="center">

![TypeForge Banner](https://img.shields.io/badge/TypeForge-v2.0-orange?style=for-the-badge)

A modern, responsive, and feature-rich **Typing Speed Test Application** built using **HTML, CSS, and Vanilla JavaScript**.

Designed with a premium futuristic UI, real-time analytics, keyboard heatmap, difficulty modes, timer customization, sound effects, dark/light themes, and performance tracking.
